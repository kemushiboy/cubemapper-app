# cubemapper：キューブ用プロジェクションマッピングアプリ

正六角形に変換したキューブ映像を、プロジェクターで実物のキューブに投影するためのアプリです。
TouchDesigner の Kantan Mapper と同じ考え方で、映像の一部（入力範囲）を、出力上の四角形（Quad）に射影変換で貼ります。

正六角形の映像は、別アプリ hexcube（立方体の3面を、外周が正六角形になる構図へ変換するツール）などで用意してください。

## ダウンロード

[Releases](https://github.com/kemushiboy/cubemapper-app/releases) から、使う OS に合ったファイルをダウンロードしてください。

| OS | ファイル |
|---|---|
| Windows | `cubemapper-Setup-<版>.exe`（インストーラー）、`cubemapper-<版>-portable.exe`（インストール不要） |
| macOS（Apple シリコン） | `cubemapper-<版>-arm64.dmg` |
| macOS（Intel） | `cubemapper-<版>-x64.dmg` |

- **Windows:** 署名していないため、初回起動時に SmartScreen の警告が出ます。「詳細情報」→「実行」で起動できます。
- **macOS:** Apple の公証を受けていないため、初回は「開けません」と表示されます。アプリを右クリックして「開く」を選ぶと起動できます。それでも「壊れている」と表示されるときは、ターミナルで次のコマンドを実行してください。

  ```
  xattr -cr /Applications/cubemapper.app
  ```

## 開発用の起動とビルド

```
npm install
npm start          # 起動
npm run dist:win   # Windows 版をビルド（dist/ に出力）
npm run dist:mac   # macOS 版をビルド（macOS 上で実行）
```

### リリース

`v` で始まるタグ（例：`v1.0.0`）をプッシュします。すると GitHub Actions が Windows と macOS でビルドし、GitHub Releases に公開します。

```
npm version patch   # package.json の版を上げてタグを作る
git push --follow-tags
```

## 基本の流れ

1. **映像を開く**：正六角形に変換した映像を開きます。ウィンドウにドラッグ＆ドロップしても開けます。
2. **キューブ3面を作成**：六角形の上面・左面・右面を入力範囲にした Quad を3つ作ります。
   - 作った直後の出力は、入力映像と同じ見た目です。
3. **出力ウィンドウを開く**：「表示先」で選んだディスプレイ（プロジェクター）に、フルスクリーンで出力します。
4. **テストパターン（T キー）**をオンにします。各面に色・グリッド・対角線が出るので、キューブに合わせやすくなります。
5. 右の **出力（プロジェクター）** で角をドラッグし、実物のキューブの角に合わせます。
   - 「重なっている角を一緒に動かす」がオンなら、面どうしで共有している角（中央の C など）は一緒に動きます。
   - Alt を押しながらドラッグすると、その角だけを動かせます。
   - 細かい合わせ込みは次の操作でできます。
     - 角を選んで矢印キー（1px）、Shift+矢印キー（10px）
     - Shift を押しながらドラッグ（動きが 1/4 になる）
6. 合ったらテストパターンをオフにして再生します。
7. **マッピングを保存**で JSON に保存します。次回は「マッピングを読み込む」で、映像も一緒に開き直せます。
   - 最後の状態は自動でも保存されていて、次回起動時に復元されます。

## 画面

| 場所 | 内容 |
|---|---|
| 入力（左） | 映像と、各シェイプの入力範囲。選んだシェイプの入力範囲の角もドラッグで調整できます |
| 出力（右） | プロジェクターに出る映像のプレビューと、各シェイプの角 |
| 出力 | 出力解像度（プロジェクターに合わせる）、表示先ディスプレイ、テストパターン、ブラックアウト |
| シェイプ | キューブ3面の作成、Quad の追加・複製・削除・重なり順、表示のオン／オフ |
| 選択中のシェイプ | 名前、不透明度、ソフトエッジ、入力範囲（六角形の上面・左面・右面、映像全体）、出力の角の数値 |
| 六角形の位置 | キューブ3面の入力範囲として使う正六角形の中心と半径。hexcube の初期設定（1920×1080・半径486）で書き出した映像なら、そのままで合います |

## キー操作

| キー | 動作 |
|---|---|
| 矢印 / Shift+矢印 | 選んだ角（角を選んでいないときはシェイプ全体）を 1px / 10px 移動 |
| Tab / Shift+Tab | 選んだシェイプの角を順に選ぶ |
| Esc | 角の選択 → シェイプの選択の順に解除。出力ウィンドウ上では、出力ウィンドウを閉じる |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直し |
| Ctrl+D / Delete | 複製 / 削除 |
| Space | 再生 / 一時停止 |
| ← → | （シェイプ未選択時）1フレーム移動 |
| T / B | テストパターン / ブラックアウト |

## しくみ

- 各シェイプの情報は次のとおりです。
  - 入力映像上の四角形 `src`（4隅）
  - 出力上の四角形 `dst`（4隅）
  - 不透明度
  - ソフトエッジ
- 描画（`src/renderer/mapgl.js`）は WebGL2 で行います。出力の各画素について、`dst` の射影変換の逆変換でシェイプ内の位置 (u,v) を求め、`src` の射影変換で映像のどこを引くかを決めます。
- この描画処理は、編集画面のプレビューと出力ウィンドウで共通です。
- 出力ウィンドウは、編集画面からマッピングの内容と再生位置を受け取って描画します。
  - 再生位置は1秒ごとに合わせ直し、0.1秒以上ずれていたら補正します。
  - 音は編集画面側で鳴ります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `src/main.js` | 編集ウィンドウ、出力ウィンドウ（表示先ディスプレイ・フルスクリーン）、両者の中継、ファイルダイアログ |
| `src/preload.js` | 画面側に公開する API |
| `src/renderer/index.html` / `style.css` / `mapper.js` | 編集画面 |
| `src/renderer/output.html` / `output.js` | プロジェクター出力ウィンドウ |
| `src/renderer/mapgl.js` | マッピングの描画（編集画面と出力ウィンドウで共用） |
| `src/renderer/geometry.js` | 射影変換などの計算（hexcube-app と同じもの） |
